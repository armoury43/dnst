# dnstune

**سریع‌ترین DNS قابل‌اعتماد را روی لینوکس پیدا کن و با امنیت کامل و بازگشت خودکار اعمال کن.**

[English](README.md) · فارسی

</div>

---

عوض کردن DNS در لینوکس معمولاً یعنی حدس زدن بهترین سرور، ویرایش دستی فایل‌ها و امیدواری به اینکه ریزولوشن خراب نشه.
**dnstune** سرورها رو از همون شبکه‌ی خودت اندازه‌گیری می‌کنه، سرورهایی که جواب‌ها رو دستکاری می‌کنن حذف می‌کنه و بعد
سیستم رو عوض می‌کنه. بعد از تغییر هم چک می‌کنه DNS هنوز کار می‌کنه و اگه نکرد، خودش تغییر رو برمی‌گردونه.

> **وضعیت: آلفا (نسخه 0.1).** هسته‌ی برنامه با تست‌های واحد پوشش داده شده، اما یکپارچگی با systemd-resolved فعلاً فقط با یک
> `resolvectl` شبیه‌سازی‌شده تست شده. اگه روی سیستم واقعی چیزی عجیب بود، خروجی `dnstune -v status` رو داخل یک issue بذار.

## چرا dnstune

- **اعتماد، نه فقط سرعت.** هر سرور برای دستکاری NXDOMAIN و برگردوندن آدرس‌های خصوصی برای دامنه‌های معروف بررسی می‌شه
  (نشونه‌ی کلاسیک سانسور و تزریق در سطح DNS).
- **امن از پایه.** اول snapshot، بعد اعمال تغییر، بعد خوندن دوباره، بعد resolve کردن یک دامنه‌ی واقعی و در هر شکستی
  بازگشت خودکار. تغییرها موقتی‌ان و با ریبوت همه‌چیز به حالت عادی برمی‌گرده.
- **پشتیبان‌های مستقل.** سرور دوم از یک **ارائه‌دهنده‌ی دیگه** انتخاب می‌شه تا قطعی یک شرکت DNS رو کاملاً نخوابونه.
- **چیزی برای خراب شدن نیست.** صفر وابستگی زمان اجرا، پارسر DNS نوشته‌شده با کنترل کامل مرزها، اعتبارسنجی سخت‌گیرانه‌ی ورودی‌ها
  و هیچ اجرای shell.
- **سریع وقتی لازمه.** یک موتور اختیاری Go (فایل باینری ثابت) صدها سرور رو همزمان تست می‌کنه. اگه نبود یا خراب شد،
  خودکار موتور پایتونی داخلی استفاده می‌شه.

## نصب

به لینوکس و Python 3.11 یا بالاتر نیاز داره. دستورهای `apply`، `revert` و `status` **systemd-resolved** هم لازم دارن.

```bash
pipx install git+https://github.com/YOUR-USERNAME/dnstune.git
```

## استفاده

</div>

```bash
dnstune list                 # فهرست سرورها
dnstune bench                # اندازه‌گیری و رتبه‌بندی
dnstune best                 # بهترین سرورها، هر کدوم در یک خط
dnstune apply --dry-run      # ببین چی عوض می‌شه، بدون تغییر
sudo "$(command -v dnstune)" apply
dnstune status
sudo "$(command -v dnstune)" revert   # برگردوندن دقیق تنظیمات قبلی
```

<div dir="rtl">

سرورهای منطقه‌ای یا خصوصی (مثل DNSهای ایرانی) عمداً داخل برنامه ثابت نشدن چون آدرس‌هاشون تغییر می‌کنه. اونها رو خودت داخل یک فایل TOML
بذار و با `--servers` بده. نمونه: [examples/custom-servers.toml](examples/custom-servers.toml).

## محدودیت مهم

DNS معمولی روی UDP/53 رمزنگاری و احراز هویت نداره و هر کسی وسط مسیر می‌تونه اون رو ببینه یا تغییر بده. dnstune بهترین سرور ممکن رو
انتخاب می‌کنه و دستکاری‌های واضح رو تشخیص می‌ده، اما نمی‌تونه خود پروتکل رو امن کنه. جزئیات در [SECURITY.md](SECURITY.md).
